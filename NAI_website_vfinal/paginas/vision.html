Área de trabajo visual

Selecciona una imagen desde tu dispositivo o dibuja directamente sobre el lienzo. Puedes cambiar el color y el grosor del trazo.




Tu navegador no es compatible con el elemento canvas.

El lienzo está listo. Puedes dibujar o seleccionar una imagen.

La imagen se procesa en tu navegador. No se envía a un servidor ni se realiza un análisis mediante inteligencia artificial real.

¿Cómo funciona?

Se utiliza FileReader para leer la imagen seleccionada y Canvas para mostrarla y dibujar sobre ella.

Cuando termines, puedes descargar el resultado en formato PNG. El archivo original de tu dispositivo no se modifica.
